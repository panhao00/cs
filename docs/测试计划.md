# 课程注册系统（CRS）测试计划

> 版本: 1.0  
> 编写日期: 2026年9月17日  
> 项目: Wylie College 课程注册系统（CRS）

---

## 1. 测试概述

### 1.1 测试目标

验证课程注册系统的功能正确性、性能表现和安全防护，确保系统满足需求规格说明书中定义的所有业务规则和非功能需求。具体目标包括：

- 验证 15 个用例的全部基本流和备选流
- 确保并发场景下数据一致性（选课不超卖、成绩不覆盖）
- 验证角色权限隔离和水平越权防护
- 确认 API 响应时间满足性能要求（80% 事务 ≤ 2 秒）
- 确保前端交互逻辑与后端 API 对接正确

### 1.2 测试范围

| 测试类型 | 范围 | 工具 |
|---|---|---|
| 单元测试 | Service 层业务逻辑、工具方法 | JUnit 5 + Mockito |
| 集成测试 | API 端点、数据库交互、事务边界 | Spring Boot Test + H2 |
| 端到端测试 | 完整用户流程（登录→选课→提交） | Playwright |
| 性能测试 | 并发选课、API 响应时间 | JMeter / 自定义脚本 |
| 安全测试 | JWT 验证、权限检查、注入防护 | 手动测试 + OWASP ZAP |

### 1.3 测试环境

| 组件 | 环境配置 |
|---|---|
| 后端 | Spring Boot 3.3 + Java 21 |
| 前端 | Vue 3 + Vite 8 + Element Plus |
| 数据库 | H2 内存库（测试）/ MySQL 8.x（生产模拟） |
| 操作系统 | Windows 10/11 |
| 浏览器 | Chrome 最新版（Playwright 支持） |
| JDK | OpenJDK 21 |

## 2. 测试策略

### 2.1 单元测试（JUnit 5 + Mockito）

**目标**: 隔离测试 Service 层业务逻辑，不依赖数据库和外部服务。

**测试方法**:
- 使用 Mockito mock Repository 层依赖
- 验证业务规则的正确性（成绩校验、时间冲突检测、容量限制等）
- 测试异常场景（用户不存在、权限不足、状态不允许等）
- 覆盖所有 public 方法的 happy path 和 error path

**已有测试**:
- `RegistrationServiceTest`（5 个用例）: 验证关闭注册的核心算法
- `ScheduleServiceTest`（15 个用例）: 课表管理、时间冲突、所有权校验
- `GradeServiceTest`（10 个用例）: 成绩录入、加密、通知
- `TeachingServiceTest`（8 个用例）: 教授选课、冲突检测
- `UserServiceTest`（12 个用例）: 用户 CRUD、SSN 唯一性
- `ReportCardServiceTest`（6 个用例）: 成绩单查询
- `AuthServiceTest`（8 个用例）: 登录认证、JWT 生成
- `BillingRetryServiceTest`（3 个用例）: 计费失败重试
- `EnrollmentStatsServiceTest`（4 个用例）: 选课统计
- 后端共 113 个单元测试，前端 46 个测试，全部通过

### 2.2 集成测试（Spring Boot Test + H2）

**目标**: 验证 API 端点、数据库操作、事务行为和 Spring Security 集成。

**测试方法**:
- 使用 `@SpringBootTest` + `@AutoConfigureMockMvc` 启动完整应用上下文
- H2 内存库提供隔离的数据环境
- 每个测试方法执行后自动回滚（`@Transactional`）
- 测试 JWT 认证流程、角色授权、CORS 配置

### 2.3 端到端测试（Playwright）

**目标**: 模拟真实用户操作，验证前端界面与后端 API 的完整交互。

**测试方法**:
- 覆盖 8 个用例的核心用户旅程
- 测试页面导航、表单提交、错误提示、通知显示
- 验证路由守卫（未登录跳转登录页）
- 截图对比验证 UI 状态

### 2.4 测试覆盖率目标

| 层级 | 目标覆盖率 | 说明 |
|---|---|---|
| Service 层 | >= 80% | 所有业务规则必须覆盖 |
| Repository 层 | >= 60% | 关键查询方法必须覆盖 |
| Controller 层 | >= 70% | 所有 API 端点必须覆盖 |
| 前端组件 | >= 50% | 核心交互组件必须覆盖 |
